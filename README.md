# SN Siding & Soffit website

Source for https://snsidingandsoffit.ca — soffit, siding, fascia and gutters in the Lower Mainland, BC.

- `public/index.html` is the whole site. Everything in `public/` goes live.
- Quote forms send through Web3Forms to snsidingandsoffit@gmail.com (FormSubmit as backup).
- Pushing to `main` redeploys the site on Cloudflare automatically (see `wrangler.jsonc`).
